# Техническое задание
# Лабораторная работа №1 — Решение квадратного уравнения

## Цель

Разработать программу на языке Python для решения квадратного уравнения вида ax² + bx + c = 0.

## Входные данные

- Три вещественных числа: коэффициенты a, b, c, вводимые пользователем с клавиатуры.
- Ограничение: a ≠ 0 (иначе уравнение не является квадратным).

## Выходные данные

- Количество вещественных корней и их значения (или сообщение об отсутствии вещественных корней).

## Требования

1. Программа должна корректно обрабатывать все три случая:
   - D > 0 — два различных вещественных корня
   - D = 0 — один кратный корень
   - D < 0 — нет вещественных корней
2. Программа должна проверять, что a ≠ 0, и сообщать об ошибке при a = 0.
3. Входные данные вводятся через стандартный ввод (keyboard).
4. Результат выводится в стандартный вывод (console).

## Ограничения

- Язык программирования: Python 3.8+
- Сторонние библиотеки не используются
- Коэффициенты — вещественные числа (float)
