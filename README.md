# Решение квадратного уравнения

Программа для нахождения корней квадратного уравнения вида **ax² + bx + c = 0**.

## Краткое назначение

Программа принимает коэффициенты a, b, c и вычисляет корни уравнения через дискриминант. Обрабатывает три случая: два вещественных корня, один корень (кратный), нет вещественных корней.

## Требования к окружению

- Python 3.8 и выше
- Сторонние библиотеки не требуются

## Инструкция по запуску

```bash
cd src
python quadratic.py
```

Программа запрашивает коэффициенты a, b, c с клавиатуры и выводит результат.

Для запуска тестов:

```bash
python -m pytest tests/
```

## Стратегия ветвления

В проекте используется **GitHub Flow** — упрощённая стратегия, подходящая для небольших проектов.

**Обоснование выбора:** проект небольшой, один разработчик, нет необходимости в сложной схеме с релизными ветками. GitHub Flow проще в поддержке, чем Git Flow.

**Схема ветвления:**

```
main (стабильная версия, всегда рабочая)
  |
  +-- develop (разработка новых функций)
  |     |
  |     +-- [фича готова] --> merge в main --> push
  |
  +-- [hotfix при необходимости] --> merge в main
```

**Правила:**
- `main` — всегда содержит рабочий код
- Новые функции разрабатываются в ветке `develop` (или именованных feature-ветках)
- После завершения работы ветка сливается в `main` через merge
- После слияния изменения сразу публикуются (push)
