# Описание проекта

## Назначение

Программа решает квадратное уравнение вида **ax² + bx + c = 0** методом дискриминанта.

## Алгоритм

1. Получить коэффициенты a, b, c от пользователя.
2. Проверить, что a ≠ 0.
3. Вычислить дискриминант: D = b² − 4ac.
4. Если D > 0: вернуть два корня.
5. Если D = 0: вернуть один корень.
6. Если D < 0: вернуть сообщение об отсутствии вещественных корней.

## Модули проекта

- `src/quadratic.py` — основная логика (функции solve_quadratic и main)
- `tests/test_quadratic.py` — набор тестов
- `docs/tz.md` — техническое задание
